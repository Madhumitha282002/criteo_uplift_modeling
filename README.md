# Criteo Uplift Modeling

Benchmarking meta-learners and causal forests for individual treatment effect estimation on the Criteo Uplift v2.1 dataset (~14M rows).

## Tech Stack

- **Data:** DuckDB, pandas, pyarrow
- **Modeling:** scikit-learn, LightGBM, scipy
- **Viz:** matplotlib, seaborn, Jupyter
- **Tooling:** ruff, black
